Framework Overview

PGVL-Gym provides a unified, extensible environment to rigorously evaluate how visual foundation models interact with large language models via prompt-based instruction in computational pathology workflows.

Core Components

Vision Backbone Integrate arbitrary vision foundation models (e.g., UNI, Hoptimus0, GigaPath)
Language Model Seamlessly attach LLMs for multi-modal reasoning and captioning
Prompt Engine Dynamically test zero-shot, few-shot, and chain-of-thought pathology prompts
Evaluation Suite Standardized metrics for classification, segmentation, and VQA tasks

Key Features

Modularity Swap out encoders or LLMs with a single config change
Reproducibility Deterministic benchmarking pipelines across diverse pathology datasets
Scalability Optimized for multi-GPU inference on massive WSI cohorts
